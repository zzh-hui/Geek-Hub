USB_safely · U盘锁

给 U 盘上锁的 Windows 安全工具：插上即锁，输对密码才能访问。

原创项目 · 开源免费 · 纯 Win32 API · 单文件约 300KB 免安装 · 当前版本 v2.1.1.5

📥 下载最新版（GitHub） ⭐ 查看源码仓库

✨ 核心功能

  • 插上即锁：U 盘接入后运行程序，锁定界面全屏置顶，输对密码才能访问 U 盘内容。
  • 自带屏幕键盘：38 键自创键盘（A-Z、0-9、符号），按解锁模式智能过滤按键。
  • 快捷键屏蔽：Win、Alt+Tab、Alt+F4 等逃逸组合全部拦截（Ctrl+Alt+Del 为系统安全序列，无法屏蔽）。
  • 密码仅存哈希：SHA256 存储，明文不落盘；密码文件原子化写入，杜绝损坏。
  • 递进惩罚：输错次数越多锁定越久，极端情况可选格式化兜底。
  • 超级模式：忘记密码可通过恢复密码重置，支持定时自动重置。
  • 安装卸载二合一：一个 exe 搞定安装与卸载，注册表零残留。

🔑 五档解锁模式

  • 无需解锁：程序待命，不锁。
  • 普通模式：纯数字密码。
  • 加密模式：纯字母密码。
  • 进阶模式：9 位数字 + 字母 + 符号混合。
  • 密钥模式：最长 500 位任意字符，符号、emoji 皆可。

修改密码时解锁模式自动跟随新密码切换；手动切换模式需验证当前密码，从设计上杜绝「密码与模式不符被锁死」。

⚡ 递进惩罚机制

累计输错后果
每满 5 次锁定时长递增 10 分钟（10 / 20 / 30 分钟…）
超过 60 次强制格式化兜底（默认关闭，需在超级模式手动开启）

锁屏界面实时显示已输错次数与剩余锁定时间，防止误触。

💡 使用教程

  1. 从 GitHub 下载 USBsafely-Setup.exe（安装/卸载二合一）。
  2. 双击运行，选择安装目录：U 盘根目录（正式使用）或硬盘目录如 C:\USBsafely（无 U 盘测试）。
  3. 首次安装设置 4 位启动密码，后续可在 setup.bat 中修改密码与解锁模式。
  4. 双击 run.bat 启动锁定；输对密码解锁后程序缩至托盘，双击托盘图标可重新锁定。
  5. 卸载：控制面板卸载，或再次运行 USBsafely-Setup.exe（需输入启动密码），文件与注册表一并清理干净。

提示：拔出 U 盘后程序自动退出；忘记密码可在设置页连点版本号 5 下进入超级模式，用恢复密码重置。

❓ 常见问题

没有 U 盘可以测试吗？
可以。安装时选一个硬盘目录（如 C:\USBsafely），它会把该目录当作「虚拟 U 盘」，测试完用卸载功能一键清干净。
忘记密码怎么办？
打开设置页，连点版本号 5 次进入超级模式，输入恢复密码即可重置锁屏密码；也可预先设置 24 小时 / 30 天 / 365 天自动重置。
为什么 U 盘插上不会自动锁？
Windows 7 起系统已禁用 U 盘自动运行（防病毒机制），插入后需双击 run.bat 启动锁定。
程序体积多大？依赖什么？
单文件约 300KB，纯 Windows 系统 API 编写，零第三方依赖，拷进 U 盘即可运行。
