网站与 Git Drive 网盘的演进记录 · 新内容在顶部

2026-11-23大版本 · Git Drive 2.0

  • 文件在线预览：txt/图片/PDF 免下载直接查看（主页网盘页与沙箱网盘页均支持）
  • 回收站：删除的文件进回收站，可一键恢复到原位置，也可彻底清除（沙箱网盘页）
  • 下载次数统计：每个文件的下载量实时可见
  • 文件安全档案：所有文件标注 SHA256 校验值与来源说明，下载前可自行核对
  • Git Drive 管理员面板：登录后可右键改名/删除、Ctrl 多选批量删除、拖拽批量上传（支持整个文件夹）
  • 主页网盘页新增「管理员登录」，与沙箱网盘账号打通

2026-11-21窗口模式

  • 窗口按钮升级为 SVG 图标，新增三种窗口模式：最小化（主页悬浮球恢复）、窗口化（弹出小窗）、最大化（回到全屏）
  • 修复最大化后未回到网盘页、最小化后按钮状态错乱的问题
  • 文件图标全部替换为内联 SVG，不再使用 emoji
  • 网盘页整体改为 Win11 文件资源管理器风格（Git Drive）：目录树、面包屑、列头排序、详情面板、搜索

2026-11-19上传与下载

  • 上传断点续传：刷新页面后重新选择文件，自动从已传位置继续，不从头来
  • 分片大小随文件体积自动分档（256KB ~ 8MB），大文件上传提速约 70%
  • 隧道切换 HTTP/2 协议，上传速度提升约 13 倍
  • 免责声明与原创声明改为页面底部直接展示

2026-11-17稳定性

  • 下载断点续传：支持标准 HTTP Range，中断后重新点击自动续传
  • 修复 Range 越界导致下载卡死的问题
  • 改名改为原地编辑，不再刷新页面

2026-11-14上线

  • Geek-Hub 网站正式上线，域名 geekhub.dpdns.org 托管至 Cloudflare
  • 云盘服务上线（pan.geekhub.dpdns.org），HTTPS 加密直连
  • 主页新增云盘专栏与 QQ 群入口
  • 管理员上传、防爆破锁定（错误次数越多锁定越久）
